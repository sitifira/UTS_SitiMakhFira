# Proyek Latihan PHP

Proyek ini berisi contoh-contoh dasar pemrograman web menggunakan PHP untuk tujuan pembelajaran.

## Struktur File

- [index.php](file:///C:/xampp/htdocs/fira_is63/index.php) - Halaman utama/welcome
- [navigation.php](file:///C:/xampp/htdocs/fira_is63/navigation.php) - Menu navigasi ke berbagai contoh
- [logika.php](file:///C:/xampp/htdocs/fira_is63/logika.php) - Contoh logika dan kondisi
- [materijum_9.php](file:///C:/xampp/htdocs/fira_is63/materijum_9.php) - Materi tentang struktur kondisi
- [jum9login.php](file:///C:/xampp/htdocs/fira_is63/jum9login.php) - Form login sederhana
- [nilai.php](file:///C:/xampp/htdocs/fira_is63/nilai.php) - Form input nilai dengan proses kondisi

## Fitur yang Dicakup

1. **Dasar PHP**
   - Variabel dan tipe data
   - Operator aritmatika
   - Output dasar dengan echo

2. **Struktur Logika dan Kondisi**
   - If-else statements
   - Switch-case
   - Operator logika (AND, OR, NOT)

3. **Form Handling**
   - Membuat form HTML
   - Memproses data dari form dengan PHP
   - Validasi input dasar

4. **Contoh Implementasi**
   - Sistem login sederhana
   - Penilaian berdasarkan kondisi
   - Kategorisasi data

## Cara Menggunakan

1. Simpan semua file dalam folder web server (misalnya di htdocs jika menggunakan XAMPP)
2. Jalankan web server Apache
3. Akses file melalui browser di `http://localhost/namafolder/`

## Catatan

Proyek ini dibuat untuk tujuan pembelajaran dan berisi contoh kode sederhana. Tidak direkomendasikan untuk penggunaan produksi tanpa modifikasi dan penambahan keamanan yang memadai.
